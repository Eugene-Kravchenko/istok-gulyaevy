# Как читать эту папку

- `dashboard.html` — состояние работы над древом.
- `family-echo-tree/2026-09-24-brief.md` — исходная просьба пользователя.
- `family-echo-tree/manifest.md` — требования и их статус.
- `family-echo-tree/spec.md` — принятые решения.
- Эта доработка одного экрана выполнена целиком, поэтому отдельные таски не создавались.

Если работа прервётся, можно попросить «продолжи автопилот».
